## Qué es este portfolio

Es un sitio de **documentación técnica** escrito en Markdown y generado con [Docsify](https://docsify.js.org). Cada página explica un procedimiento real de forma que cualquiera pueda **repetirlo**: contexto, tablas de referencia, comandos y avisos sobre los errores típicos.

| Característica | Cómo se consigue |
|---|---|
| Legible | Una página por procedimiento, títulos jerárquicos y menú lateral |
| Reproducible | Comandos exactos en bloques de código, con el sistema operativo indicado |
| Fácil de mantener | Texto plano versionado con Git; cada `git push` a `main` republica el sitio |
| Siempre disponible | Copia local en `http://localhost:3000` y versión web en GitHub Pages |

> [!NOTE]
> Las páginas se escriben y revisan primero en local con `docsify serve`; después se publican automáticamente mediante GitHub Actions. El procedimiento completo está en [Proyecto: este portfolio](ut7/portfolio-docsify.md).

```bat
:: En CMD, desde la raíz del repositorio
docsify serve ./docs
```

Después abre `http://localhost:3000` en el navegador.
